  • 发展脉络
    • 1980s-2017：启发式规则 + 强化学习
      • 对规则打分给奖励
      • 弊端：奖励黑客，钻评估机制空子、能力没真提升
    • AlphaZero：自博弈
      • 启发式规则 → 模型权重
      • 自己生成数据训练自己
      • 局限：目标受限，仅限具体场景
    • LLM 时代：语言反馈
      • 大模型能评判好坏，替代人工指导
      • Reflexion（2023）：错题本式反思，失败后总结复用
    • 内部化学习（2022-2024）
      • STaR：自举推理，保留正确推理过程微调自己
      • 解法：逆向推理，先扶后放（像教骑车）
      • 局限：目标仍需人工设计（如 DPO 需人类示范）
    • 评价体系演进（2022-2025）
      • RLAIF：AI 对照人工写的原则打分
      • Self-Rewarding（2024）：回答 + 自我评分，交叉验证
      • Meta-Rewarding（2024）：评委的评委
      • 隐患：评判尺度自我弯曲、陷入自我确认
    • Agentic 时代：agent 迭代阶梯
      • 改提示词（AB 测试、版本管理）
      • 改上下文（自我决策调研什么、组织什么）
      • 改工作流（构造与编排流程）
      • 改执行代码（agent 架构）
      • 改优化器（改"怎么改"本身）
      • 实例：提示词自优化（orbo 类）、工作流搜索（ADS-Flow 2025）、自我改进系统（DGM）、真实环境闭环（Melo 类）
    • 真实环境闭环：用户驱动
      • 从题库驱动 → 用户驱动
      • 复盘执行记录，自我搜索、自我评估、自我接纳新版本
      • 用户具体情况成为奖励信号，越真实越难钻空子
    • 更开放的自由度
      • Self-Adapting LM：自己定学习计划、准备材料
      • MOTO：机器人策略自选动作（世界模型预测 + 价值模型判断）
      • AI 参与模型研发（OpenAI / Google / Anthropic）
    • 远方：套娃
      • 自动研究系统去研究并改进自动研究系统
      • 递归式 agent 改进，评委的评委的评委
  • 未点火的核心问题
    • 验证器是否可靠
    • 奖励黑客能否被避免
    • 改进能否跨越数据分布界限
    • 能力、控制、复杂度同步上升
    • 终极之问：真变好了，还是学会了"看起来变好"？
