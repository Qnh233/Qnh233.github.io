VISTA：给多模态模型一双"会回看"的眼睛

从文本数字网格到无损视觉记忆——多模态 Agent 的一次"回归本真"

Qiushi Han · Keya Hu · Linlu Qiu · Cathy Wu · Kaiming He ｜ MIT ｜ 2026-10 ｜ 代码：github.com/joshhhhhan/VISTA

一句话总结：多模态模型本身就"会推理"，缺的只是一个正确的视觉驾驭框架（harness）——给模型"原始视觉观察 + 无损视觉记忆 + 自主检查工具"，它就能在陌生交互环境里完成长程推理。VISTA 用这套极简设计在 ARC-AGI-3 上拿到满分 RHAE 100.00，且成为首个不依赖程序合成就达到满分/近满分的系统。

一、是什么（What）：一个"长程视觉"驾驭框架

VISTA（Visual Harness for Reasoning in an Interactive World）不训练任何模型，它是一层接在通用多模态模型外面的纯机械接口，由三大组件构成：

① 视觉观察 Visual Observation

环境以渲染图像直接输入（而非文本网格），保留物体的外观与空间关系，让模型充分发挥视觉先验。ARC 中 64×64 帧放大 8× 为 512×512 输入。

② 无损视觉记忆 Lossless Visual Memory

环境返回的每一帧（含中间动画帧）全分辨率保存，按「回合 turn / 帧 frame」索引，存在上下文之外，永久可查、绝不压缩。

③ 视觉检查 Visual Inspection

模型主动决定查什么：空间上放大任意矩形区域、时间上回溯任意早期帧、read_pixels 精确读取像素数值。

二、为什么（Why）：解决"编码时不知道哪块信息以后有用"

ARC-AGI-3 是一组规则和目标都不给的交互式视觉游戏，agent 必须在陌生世界里通过试错发现规则、跨关卡迁移理解。此前主流做法有两条路线，各有硬伤：

语言路线 把 64×64 画面转写成文本数字网格（每格一个整数颜色索引），再靠 LLM 读网格、写程序验证（program synthesis）。问题：每帧约 4,000 token 极贵；转写丢失视觉细节；环境越复杂，显式程序化抽象越难。

传统多模态路线 每张图只编码一次成视觉表征进入上下文。问题：表征是有损压缩；编码时模型不知道哪些细节以后会关键；上下文一满，旧帧被丢弃或被文本摘要替换——等模型知道要回看时，原图早就没了。

VISTA 的答案：把"决定看什么"从编码时刻推迟到推理时刻。记忆全量被动保存（harness 机械行为，零上下文成本），注意力由模型主动调用（inspect 查哪帧、裁哪块、读哪些像素）——相当于给模型一个覆盖整个交互历史的显式注意力机制。

三、怎么用（How）：观察 → 推理 → 行动，按需回看

每回合模型与 harness 多轮对话：接收当前视觉状态，自由语言推理（假设 → 预测动作结果 → 规划），可随时检查记忆与笔记，最后用 play 执行一个动作。上下文中只放"当前帧 + 临时检索结果"，历史全在外部存档——所以记忆不会随上下文清空而丢失。

六、思考感悟：这可能是这个领域的"回归本真"

读完 VISTA，一个很强烈的直觉是——它和何恺明团队最近那篇《Back to Basics: Let Denoising Generative Models Denoise》（CVPR 2026）是同一个"回归本真"叙事的两面。

扩散那边：今天的扩散模型其实并没有在"去噪"——它们预测的是噪声（或带噪量），而不是干净图像。这篇论文主张直接预测干净像素，回归"去噪"这个词的本义。数据天然落在低维流形上，而噪声量不落在上面——预测干净数据才是更本质的目标。

Agent 这边：主流做法给模型套了层层中间抽象——把画面转成文本网格、再建可执行程序、再用搜索验证。VISTA 把这些全剥掉，让模型直接看画面、直接用自然语言推理、直接回看原始证据，回归"感知世界"的本义。

两条线的共同点非常清晰：去掉中间复杂过程，回到直接目标。

  • 扩散：预测噪声（中间量）→ 直接预测干净像素
  • Agent：文本网格 + 程序合成（中间抽象）→ 直接视觉感知 + 按需回看原始帧

更深一层的启示：模型的基础能力可能被我们严重低估了——缺的不是更强的模型，而是一个简单、正确、把能力释放出来的接口。VISTA 换输入表示（文本→图像）就 +34 分、加记忆与检查再 +24 分，全程没动任何参数。这也解释了为什么它对 100K 小上下文依然稳健：它根本不靠"塞更多历史进上下文"，而是把历史放在外面、需要时再精确取用。

附：VISTA 对 3D 渲染同样鲁棒（RHAE 84.12，远超文本基线），说明这套"直接视觉"路线不挑表示形式，进一步支持"回归本真"的判断。

七、局限与后续

局限（论文自认）：① 模型自身能力仍是成功的决定性因素，harness 只是"解锁"；② 数据污染风险——模型发布于基准之后，不排除公开游戏进入训练数据，需要在 ARC-AGI-3 私有集上验证；③ 动作开销不小（3D 下需 20,640 个动作）。

后续方向：① 计算机使用 / GUI agent 基础设施（无损截图记忆 + 区域检查天然契合浏览器与桌面自动化）；② 具身智能——更接近物理世界的环境；③ 与程序合成互补而非对立（VISTA 做感知与记忆，程序做验证与搜索）；④ 用 harness 生成高质量交互轨迹，训练原生具备"长程视觉记忆"的 agent（把工具能力内化成模型能力）；⑤ 作为"无限上下文"的廉价替代方案。
