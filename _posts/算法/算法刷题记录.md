## 链表

- 对于有可能操作头结点的问题，记得加上哨兵。
- 对于单链表，要删除结点一般都要用pre指针。有时候只用pre来遍历就挺好。
- 链表排序用归并，可用递归归并。【归并排序不需要随机访问，所以天然适配链表】
- 深拷贝要么用哈希记录位置，要么直接原地插入用原节点位置标记新节点位置。不可直接改变引用。要新建。
- LRU 缓存，要想实现O1时间复杂度，需要用双向链表来记录前后关系，并且能从任何位置快速找到其前驱和后继，方便删除。使用哈希表存key-Node 来快速访问对应key 的缓存node，双向链表存node的相对位置，最近访问的放到表头，优先删除表尾的数据。

    - 用分治来写即可
- 二叉搜索验证
    - 这里不能用纯递归的方式去验证子树满足二叉搜索（左小右大）了，因为其左小右大的过程不仅仅是局部满足就行，还要考虑全局的满足。即子树的子树要满足子树的范围约束（右子树的左子树满足小于子树根结点也要满足大于根结点的要求）。所以用一个外围范围约束即可，把这个约束传递下去就能形成全局的约束。
- 二叉搜索的第k小的元素
    - 二叉搜索树 用中序遍历就是升序遍历，记录个数到第k个返回。
    - 中序遍历就是 左子树走到头，出栈输出，转右子树。

- 二叉树右视图
    - 无论几叉树，用层序遍历，能统计出每层的节点数量，那么也就能知道什么时候到了该层的开始和结束，以及记录树的深度。我这里就在每层最右侧记录一下非空值就可以了。
- 二叉树拉成链条
    
    - 递归法 ： 先递归展开 再每次把左子树移动到最右下节点后，之后再把原来的右子树接上去。这样从下到上这样接，就能保证每次子树都是形成好的局部链条，再接到右边就行。
    
    ```Python
    # 递归展开左、右子树 → 左子树插到根和右子树中间 → 左指针置空
            if not root:
	            return
            
            # 先递归展开左右子树
            self.flatten(root.left)
            self.flatten(root.right)
            
            # 保存右子树
            right = root.right
            
            # 把左子树移到右边
            root.right = root.left
            root.left = None
            
            # 找到现在右子树的最后一个节点
            while root.right:
                root = root.right
            
            # 把原来的右子树接上去
            root.right = right
    ```  
    - 迭代法： 从上至下，每次吧左子树放到右边，右边原子树接在后面，然后往右下走遍历就行。


    ```Python
    def flatten(root: Optional[TreeNode]) -> None:
        cur = root
        while cur:
            # 如果当前节点有左子树
            if cur.left:
                # 找到【左子树】里最右下角的节点
                pre = cur.left
                while pre.right:
                    pre = pre.right
    
                # 把当前节点的右子树，接到左子树最右下角
                pre.right = cur.right
    
                # 把左子树搬到右边
                cur.right = cur.left
                cur.left = None
    
            # 继续处理下一个节点
            cur = cur.right
    ```
    
- 前序与中序构造二叉树
    - 根据前序中序的特性，提取根节点后再提取其左右子树。
    - 一般用递归，加上哈希快速定位中序遍历中的根结点。记得传递所代表子树区域的left right
- 路径总和
    
    - 这个就是求某一段的和是t，可用遍历递归或者前缀和递归
    - 遍历递归就是记录每一个节点往下走所满足和为t的数量。往下每走一步就改变要找的目标t-node.val
    - 前缀和就是遍历并统计所有前缀和的出现次数，每个结点计算当前前缀和-t的出现次数，就是满足条件的次数。（因为到了该节点了，我们要找的是满足当前前缀和-t的数，所以那个数有多少个就+多少统计计数）
        
- 最近公共祖先
    
    - 递归法
        - 用一个记录最近公共祖先，当满足两边子树返回true（即存在p or q），则记录这个作为最近公共祖先。   
        - 不用额外空间记录，直接递归下去然后上来，哪里返回了值就继续返回这个值。这样会把符合要求的那部分往上走，找到最近的公共祖先也往上走最后返回出来。

## 回溯

- 全排列
    - 全排列不考虑顺序，则可以用flag记录然后回溯所有排序情况（可回头）
- 子集
    - 子集要求顺序的话，则要用start下标来防止回头。用start防止重复
- 电话号码组合
    - 如果是char拼接字符串，其实在传参的时候串拼接结果是不影响原结果的，所以可以不回溯
- 组合总和
    - 本身可重复，但是顺序还是不能重复，就从自己开始遍历回溯。
- 括号生成
    - 这里在回溯中加上条件追加即可，用一个整形记录左括号大于右括号数量，左括号较多才能追加右括号，其他情况左右都可追加。结束条件记得1. 到末尾了退出 2.到末尾同时括号插值=0才是符合题意的追加res进去。
- 单词搜索
    
    - 类似图论迷宫了，用dfs即可，用字符追加，和前面的电话号码组合差不多。也像前缀树。匹配就往下走。
- 分割回文串
    
    - 分割这种，**顺序**而且**连续**的情况下，使用start标记不回头，然后追加的时候用[start:i+1]。

## 二分查找

顺序数组中，可随机存取的。可用二分查找。二分查找过程中也可加其他判断，比如类似dp的求和、判断是否有序（比较两边）等等。

- 单纯搜索，记得用左闭右闭的时候 退出条件用i<=j 且mid都+1；
    
- 矩阵搜，可以分开先搜行再搜列，也可以直接排成一维搜
    
- 查找元素首次位置和最后一次位置
    - 这里就要加上判断了，我们可以用二分找到最后一次小于target位置和第一次大于taget值的位置。 
- 旋转排序数组
    - 可用一次二分查找解决，记得判断是否有序。
    - 分两次也可以，一次二分找旋转分界点，一次二分找对应target
- 旋转排序数组中最小值
    - 一次二分查找找分界点即可，分界点可以是最小值也可以是旋转点。

# 多维动态规划

dp里一般每个维度都会多一个分量，0位置无意义，从1位置开始才是真正存的位置。

- 不同路径
    
    - 二维dp，因为只向下向右走，也可以只用一维dp记录最小的行的最小列最小路径
        
    
```Python
            f = [0] * (n + 1)
            f[1] = 1
            for _ in range(m):
                for j in range(n):
                    f[j + 1] += f[j]
```
    
- 最小路径和
    
    - 从左上角走到右下角，求最终权重最小的路径。
        
    - dp[i][j] 代表 [i][j]处 权重最小的路径下的权重值。
        
    - dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + cur_val
        
    - 由于在第一行第一列上只能从一个方向来，要单独处理。
        
- 最长回文字符串
    
    - 不要尝试对所有长度串判断是否回文，思考对一个回文串如何扩展判断，使得判断为O(1)。
        
    - 以每个字符串开始左右扩展，满足回文则加入并计入长度。
        
- 最长公共子序列
    
    - 子序列不要求连续
        
    - 通俗讲就是双指针来匹配加记忆，匹配上了就ij一起动，不然就选较大的j动或者i动
        

```Python
        n, m = len(s), len(t)
        f = [[0] * (m + 1) for _ in range(n + 1)]
        # f[i][j] 代表 左字符串以i下标结尾  右字符串以j下标结尾 所匹配的最长子序列长度。
        for i,x in enumerate(s):
            for j,y in enumerate(t):
                if x == y:
                    # 匹配上了 
                    f[i + 1][j + 1] = f[i][j] + 1 
                else:
                    f[i + 1][j + 1] = max(f[i][j + 1], f[i + 1][j])
        return f[n][m]
```
