# 基本概念和术语
数据是信息的载体，描述客观事物属性供计算机程序识别和处理的符号集合。

数据元素是数据的基本单位，通常作为一个整体考虑和处理，可由若干个数据项组成，数据项是构成数据元素的不可分割的最小单位。

数据对象是具有相同性质的数据元素集合，是数据的一个子集。

数据类型是一个值的集合和定义在此集合上的一组操作的总称（<font style="color:rgb(77, 77, 77);">一个值的集合怎么理解呢，比如在C语言中，</font>[char类型](https://so.csdn.net/so/search?q=char%E7%B1%BB%E5%9E%8B&spm=1001.2101.3001.7020)<font style="color:rgb(77, 77, 77);">数据范围是：-127~128,。而一组操作可以理解为类型所支持的操作方式，比如int和char类型支持+、-、*、/、%这5种操作。</font>）

    1. 原子类型 值不可再分
    2. 结构类型 可在分解乘若干分量的数据类型 struct
    3. 抽象数据类型 抽象数据组织以及相关的操作 ADT （栈队列 list map 等等）
        1. 是数学模型，定义了逻辑结构以及对数据的操作，但不提供内部实现细节和存储方式，定义了数据的行为。可以利用此将多个数据组合在一起作为整体来操作。
![](../../assets/attachments/Pasted%20image%2020261029154819.png)
数据结构是相互之间存在一种或者多种特定关系的数据元素的集合。  数据之间的某种相互关系成为结构。

数据结构包含三部分 1. 逻辑结构 2. 物理结构（存储结构） 3. 数据的运算（操作）

数据的逻辑结构和存储结构是密不可分的，一个算法的设计取决于所选定的逻辑结构，而算法的实现依赖于所采用的存储结构。

但逻辑结构和存储结构是也相互独立的。一个逻辑结构可以采用不同的存储结构，存储结构只是在计算机中的存储表现形式不同。

# 三要素
## 逻辑结构
数据元素之间的逻辑关系，从逻辑关系上描述数据。与数据存储无关，独立于计算机。

![画板](https://cdn.nlark.com/yuque/0/2024/jpeg/26089136/1710662359759-901d54e4-bc97-4604-bd9b-ee116cb0020c.jpeg)

## 存储结构
数据结构在计算机中的表示（映像），也称物理结构。包括数据元素的表示和关系的表示。存储结构是用计算机语言实现的逻辑结构，依赖于计算机语言，主要有
    1. 顺序存储
        1. 逻辑上相邻的数据元素在物理上也相邻，使用相邻的一整块存储单元。
        2. 优点
            1. 可随机存取
            2. 存储密度高
        3. 缺点
            1. 插入与删除元素代价高
            2. 需要预留空间。
        4. 应用
            1. 数组-顺序表-串
            2. 查找 排序
            3. 树
    2. 链式存储
        1. 不要求逻辑上相邻的数据元素在物理上也相邻，借助指示元素物理地址的指针来表示元素之间的逻辑关系，使用时不先预留存储空间。
        2. 优点
            1. 插入删除代价低
            2. 使用存储空间更灵活，动态长度，不需要预留空间。
        3. 缺点
            1. 只支持顺序存取
            2. 存储密度低
        4. 应用
            1. 链表 
            2. 散列表
            3. 树
    3. 索引存储
        1. 存储元素同时还建立附加的索引表。索引项一般是 K 和 V，关键字和地址。
        2. 优点
            1. 检索速度快
        3. 缺点
            1. 索引表会额外占据空间
            2. 增删数据元素也要同步修改索引表内容 （时间成本）
    4. 散列存储
        1. 根据元素的关键字直接计算出该元素的存储地址，也成为 哈希 Hash 存储
            1. 优点
                1. 检索查找、增删都很快
            2. 缺点
                1. 会造成冲突碰撞，解决冲突需要额外的时间空间开销。
                2. 散列函数不易确定

## 数据的运算
包括元素的定义和实现。**运算定义**针对逻辑结构（要用什么逻辑去解决问题，构思怎么做，需要做到什么样），指出运算的功能；**运算的实现**是针对存储结构的，指出运算的具体操作步骤。（代码）



# 算法
##  基本概念
对特定问题求解步骤的一种描述，是指令的有限序列。

五个基本特征，首先保证完成任务。

1. 有穷性  可在规定时间完成
2. 确定性 每条指令必须有其确切的含义，对于相同的输入必须有相同且确定的输出
3. 可行性   其中的操作都可以通过已经实现的运算执行有限次来实现
4. 输入 0 或多个输入   某个特定对象的集合
5. 输出 1 或多个输出   与输入有着某种特定关系的量

四个算法优良特征又快又好

1. 正确性 正确解决问题
2. 健壮性 输入非法数据能处理，能处理异常和非法数据而不会产生意料之外的结果。
3. 可读性 指令代码高可读，易理解
4. 高效率和低存储量 

## 度量算法效率
### 时间复杂度
一个语句的频度-在算法中被重复执行的次数，所有语句的频度之和记为 T（n），n 是算法问题规模。

而度量时间复杂度主要分析其 T（n）的数量级，经常找算法中深层循环的语句来确定数量级，即 f(n)

T（n）=O（f（n））

O 代表 Tn 的数量级。即 Tn 和 fn 在正整数集合上的两个函数，则存在正常数 C 和 n_0，使得当 n≥n0 时，都满足 0 ≤Tn≤C*fn

算法时间复杂度不仅依赖于问题规模，也取决于待输入数据的性质（如初始状态等）

### 空间复杂度
Sn 位该算法所耗费的存储空间，也是 n 的函数。记为 Sn=O（gn）

程序执行过程中除了本身所用指令常数变量和输入数据外还需要存储对数据进行操作的工作单元和一些辅助计算所需要的辅助空间。原地算法是 O（1）

栈深度也是空间复杂度
