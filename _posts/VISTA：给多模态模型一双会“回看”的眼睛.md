**一句话**：多模态模型本身就 "会推理"，缺的只是一个正确的视觉驾驭框架 —— 原始视觉观察 + 无损视觉记忆 + 自主检查工具，就足以在陌生交互环境里长程推理（ARC-AGI-3 满分）。

**一、是什么（What）**—— 三大组件：

- ① 视觉观察：渲染图像直接感知（非文本网格）
- ② 无损视觉记忆：每一帧全分辨率保存，按回合 / 帧索引，在上下文之外
- ③ 视觉检查：空间放大任意区域 / 时间回溯任意帧 / `read_pixels` 读像素

**二、为什么（Why）**—— 解决 "编码时不知道哪块信息以后有用"：语言路线（文本网格～4000 token / 帧 + 程序合成）和传统多模态（一次编码、有损、满了就丢）都被绕开。

**三、怎么用（How）**——Observe → Reason → Act 流水线，`play` 是唯一计费动作；上下文只放当前帧，历史全在外部存档。

**四、效果（Diff）**——RHAE 100.00（Opus 5.0）/ 99.00（GPT-5.6 Sol），25 关全通，动作数比人类首次玩家 **-57.4%**；消融 13.33 → 99.00，最大跳跃来自记忆 + 检查（70.05 → 94.10）；图像 token 便宜一个数量级。

**五、泛化**——GameWorld 超新手人类、AI GameStore 超人类中位数、BabyVision 41% → 63.2%（静态单图靠 inspect 也 +22 分）。

**六、思考感悟：回归本真**（你的核心观点）

- 扩散那边：何恺明团队《Back to Basics: Let Denoising Generative Models Denoise》（CVPR 2026）主张**直接预测干净像素**，回归 "去噪" 本义 —— 传统扩散模型预测的是噪声，不是干净图像。
- Agent 这边：VISTA 剥掉文本网格和程序合成，**直接看画面、直接自然语言推理、直接回看原始证据**。
- 共同点：**去掉中间复杂过程，回到直接目标**；启示是模型能力可能被低估，缺的是简单正确的接口。

**七、局限与后续**—— 模型能力仍是主因、数据污染风险；后续指向 GUI agent、具身智能、与程序合成互补、用 harness 轨迹训练原生 agent。
