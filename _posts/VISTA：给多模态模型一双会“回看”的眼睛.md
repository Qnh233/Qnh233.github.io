**一句话**：多模态模型本身就 "会推理"，缺的只是一个正确的视觉驾驭框架 —— 原始视觉观察 + 无损视觉记忆 + 自主检查工具，就足以在陌生交互环境里长程推理（ARC-AGI-3 满分）。

**一、是什么（What）**—— 三大组件：

- ① 视觉观察：渲染图像直接感知（非文本网格）
- ② 无损视觉记忆：每一帧全分辨率保存，按回合 / 帧索引，在上下文之外
- ③ 视觉检查：空间放大任意区域 / 时间回溯任意帧 / `read_pixels` 读像素
![Figure 3：VISTA 三大组件与每轮流水线](/assets/img/posts/vista-fig3-designs.png)

**图 1 ｜ 论文 Figure 3：**VISTA 的关键设计。(a) 视觉观察：64×64 文本网格渲染成图像；(b) 无损记忆：环境返回的每一帧以全分辨率保存并按索引寻址；(c) 视觉检查：空间上任意区域放大、时间上任意早期帧回溯；(d) 每轮流水线：Observe → Reason → Act，`play` 是唯一消耗动作数的步骤。来源：arXiv:2610.02200

**二、为什么（Why）**—— 解决 "编码时不知道哪块信息以后有用"：语言路线（文本网格～4000 token / 帧 + 程序合成）和传统多模态（一次编码、有损、满了就丢）都被绕开。
![](/assets/attachments/Pasted%20image%2020261029155806.png)
**图 2 ｜ 论文 Figure 6：**同一种状态分别表示为文本网格（左，约 4,000 token/帧）与 2D 图像（右，约 308 token/帧）。图像表示性能相当（RHAE 96.75 vs 99.00）却动作更少、每游戏 token 从 71.9M 降到 30.7M。来源：arXiv:2610.02200

**三、怎么用（How）**——Observe → Reason → Act 流水线，`play` 是唯一计费动作；上下文只放当前帧，历史全在外部存档。
![](/assets/attachments/Pasted%20image%2020261029155859.png)
**图 3 ｜ 论文 Figure 2：**VISTA 在 ARC-AGI-3（左）与 GameWorld（右）的真实轨迹——观察、推理、检查、行动交错进行。左：agent 发现橙色方块点击后变 X 标记，立即 `inspect` 放大区域确认细节并更新 GUIDE 笔记；右：Fireboy 跳空化成灰烟，agent 放大落点区域复盘死局。来源：arXiv:2610.02200


**四、效果（Diff）**——RHAE 100.00（Opus 5.0）/ 99.00（GPT-5.6 Sol），25 关全通，动作数比人类首次玩家 **-57.4%**；消融 13.33 → 99.00，最大跳跃来自记忆 + 检查（70.05 → 94.10）；图像 token 便宜一个数量级。

**消融实验**把各组件贡献拆得清清楚楚（GPT-5.6 Sol, max）：

|配置（逐步叠加）|RHAE|说明|
|---|---|---|
|官方实现（文本网格基线）|13.33|官方报告值|
|(i) 换用图像观察|47.32|单换输入就 +34 分，图像 token 便宜一个数量级|
|(ii) 放宽动作/时间限制|51.66|官方限制导致跑不完|
|(iii) 连续对话 + 原生压缩|65.82|历史不再被简单截断|
|(iv) 增加 GUIDE/WORKING 笔记|70.05|跨上下文携带理解|
|(v) + 无损视觉记忆与检查|94.10|**最大飞跃 +24 分**：VISTA 招牌组件|
|(vi) + read_pixels 精确像素读取|99.00|完整 VISTA|

**五、泛化**——GameWorld 超新手人类、AI GameStore 超人类中位数、BabyVision 41% → 63.2%（静态单图靠 inspect 也 +22 分）。

同一套接口几乎零适配地迁移到三个新环境，证明它是通用视觉 harness 而非 ARC 专用方案：

|基准|内容|VISTA 成绩|
|---|---|---|
|GameWorld|34 个浏览器游戏、170 个任务（吃豆人/Mario/2048/Fireboy…）|超越新手人类基线|
|AI GameStore|10 个公开浏览器游戏（Aqua Sort/Megaman…）|超过人类中位数基线|
|BabyVision|39 道静态视觉追踪题（迷宫 + 连线）|41.0% → **63.2%**|

BabyVision 最耐人寻味：**静态单图、没有交互历史**，仅靠 `inspect` 放大局部区域就把准确率提升 22 个百分点——"主动检查"本身的独立价值被单独验证了。

**六、思考感悟：回归本真**（核心观点）

- 读完 VISTA，一个很强烈的直觉是——**它和何恺明团队最近那篇《Back to Basics: Let Denoising Generative Models Denoise》（CVPR 2026）是同一个"回归本真"叙事的两面。**

**扩散那边：**今天的扩散模型其实并没有在"去噪"——它们预测的是噪声（或带噪量），而不是干净图像。这篇论文主张**直接预测干净像素**，回归"去噪"这个词的本义。数据天然落在低维流形上，而噪声量不落在上面——预测干净数据才是更本质的目标。

**Agent 这边：**主流做法给模型套了层层中间抽象——把画面转成文本网格、再建可执行程序、再用搜索验证。VISTA 把这些全剥掉，**让模型直接看画面、直接用自然语言推理、直接回看原始证据**，回归"感知世界"的本义。

两条线的共同点非常清晰：**去掉中间复杂过程，回到直接目标。**

- 扩散：预测噪声（中间量）→ **直接预测干净像素**
- Agent：文本网格 + 程序合成（中间抽象）→ **直接视觉感知 + 按需回看原始帧**

更深一层的启示：**模型的基础能力可能被我们严重低估了**——缺的不是更强的模型，而是一个简单、正确、把能力释放出来的接口。VISTA 换输入表示（文本→图像）就 +34 分、加记忆与检查再 +24 分，全程没动任何参数。这也解释了为什么它对 100K 小上下文依然稳健：它根本不靠"塞更多历史进上下文"，而是把历史放在外面、需要时再精确取用。

附：VISTA 对 3D 渲染同样鲁棒（RHAE 84.12，远超文本基线），说明这套"直接视觉"路线不挑表示形式，进一步支持"回归本真"的判断。

**七、局限与后续**—— 模型能力仍是主因、数据污染风险；后续指向 GUI agent、具身智能、与程序合成互补、用 harness 轨迹训练原生 agent。
**局限（论文自认）：**① 模型自身能力仍是成功的决定性因素，harness 只是"解锁"；② **数据污染风险**——模型发布于基准之后，不排除公开游戏进入训练数据，需要在 ARC-AGI-3 私有集上验证；③ 动作开销不小（3D 下需 20,640 个动作）。

**后续方向：**① 计算机使用 / GUI agent 基础设施（无损截图记忆 + 区域检查天然契合浏览器与桌面自动化）；② 具身智能——更接近物理世界的环境；③ 与程序合成**互补**而非对立（VISTA 做感知与记忆，程序做验证与搜索）；④ 用 harness 生成高质量交互轨迹，训练原生具备"长程视觉记忆"的 agent（把工具能力内化成模型能力）；⑤ 作为"无限上下文"的廉价替代方案。
